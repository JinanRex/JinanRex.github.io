# Hongyi Cen — Personal Research Homepage

Personal academic homepage for Hongyi Cen, Ph.D. candidate in Computer Science at Zhejiang University.

The site focuses on:
- Social media information integrity
- Misinformation and fact verification
- Trustworthy NLP and multilingual RAG security

## Local preview

Open `index.html` in a browser. The site is static HTML, CSS, and JavaScript and is deployed with GitHub Pages.

## Updating content

- Edit publication details in `index.html`.
- Update layout and visual styling in `style.css`.
- Update the BibTeX interaction in `script.js`.
